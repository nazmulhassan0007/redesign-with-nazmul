## Using a reference the user shares (screenshot or link)
1. Name the section type and the one signature idea (layout, type treatment, motion, or interaction).
2. Extract the system: grid, type scale, spacing rhythm, color roles, radius, motion timing.
3. Rebuild with the user's content and tokens. Take the idea, never copy the brand, copy text, or images.
4. Run the normal pre-flight check.
