# DESIGN.md Example Library

18 real-world design-system write-ups collected by github.com/ibelick/ui-skills (MIT). Use them to (a) learn how a strong DESIGN.md is structured, and (b) borrow a *direction* when a user says "make it feel like X".

Rules: borrow structure, density, type logic, and color-role thinking. Never use another company's logo, name, wordmark, or claim official authorship. Swap in the user's own brand.

| mintlify.md | Docs + marketing, token-only discipline |
| clerk.md | Developer auth product, crisp UI components |
| firecrawl.md | Dev tool, heat-orange accent on near-neutral, ASCII flavor |
